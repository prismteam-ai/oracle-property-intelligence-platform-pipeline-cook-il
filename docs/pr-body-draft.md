## What was built

- **Sources (all real, Cook County IL):** Assessor Parcel Universe (`pabr-t5kh`), Residential Characteristics (`x54s-btds`), Parcel Addresses (`3723-97qp`), Parcel Sales (`wvhk-k5uv`), Assessor Permits (`6yjf-dfxs`); City of Chicago Building Permits (`ydr8-5enu`) and Business Licenses (`r5kz-chrr`); IDFPR Roofing Contractor licenses (`pzzh-kp68`). 10.4 M rows fetched with resumable paged downloads, 0 failed pages.
- **Loaded (run `20261111T113057Z`):** 1,864,469 properties (1,861,471 with coordinates), 1,607,387 permits (139,830 roofing; 6,655 open roofing), 33,611 licensed roofing contractors (58,902 permit links), 1,211,176 businesses, 2,688,811 sales.
- **Roofing signals:** roof age per the kit contract (completed reroof permit → high, new-construction permit → medium, year built → low; open permits never reset; cancelled/expired permits never anchor an age; anchors before 1900 or before the year built are quarantined; 979,501 roofs older than 15 years), permit open duration, contractor identity from the state licensing roster, out-of-area owners (68,740), no ownership change in 10+ years (541,242 as of run `20261111T113057Z`; the count moves as sales cross the 10-year mark).
- **Continuous ingestion → publication → serving (automatic):** three independent services on the host. Ingestion every 6 h (≈ 2.5 min): each source fetches its own `:updated_at` window concurrently and a failing source becomes a dead letter without stopping the others; idempotent upserts by `(source_system, source_record_key)` + content hash; run history with inserted/updated/unchanged deltas, dead letters, limitations. A publisher checks hourly and publishes the newest run when data changed since the last publication (≈ 7 min, without blocking ingestion). The web switches to a newer verified publication within a minute, without a restart. Examples: run `20261111T090844Z` was ingested at 09:08 UTC, published automatically at 09:18 and served at 09:19; run `20261111T113057Z` picked up real upstream changes (436 Chicago business-licence rows and the republished IDFPR licence roster, 34,119 rows: businesses +247 inserted / 136 updated, contractors +51 / 5), was ingested 11:30–11:33 UTC, published automatically at 11:41 (both pins, manifest pinned) and served within a minute; Cook County and Chicago permit feeds had no new rows past their watermarks.
- **Roofing classifier, measured:** run `20261111T090844Z` stopped counting rooftop units, equipment or antennas on a roof and new-garage roof geometry (161,709 → 147,098 roofing permits). Run `20261111T113057Z` uses Chicago's `permit_type`: outside the Easy/Express reroof tracks, renovation and new-construction permits count only when they are roof jobs (explicit reroof wording, no renovation markers), plus negations and patio/terrace/dormer patterns (147,098 → 139,830; open 7,252 → 6,655). On the hand-labelled list of roofing permits open ≥ 3 years, precision rose from 21/91 (23%) to 17/30 (57%); labels, method and trade-offs in `docs/evidence/roofing-classifier-precision.md`. Permit deltas report source-record changes only, so reclassification shows in the property deltas and these counts.
- **IPFS:** CIDv1 directory root per run, CAR per root, manifest with cid/name/size/codec/sha256 for every object, previous-CID chain, verification from independent public gateways (size + digest), re-verified from GitHub Actions.
- **Query layer:** DuckDB file + Parquet snapshot; read-only SQL console (one SELECT/WITH statement, comments stripped, balanced parentheses, row cap enforced by a wrapper, sandbox without file or network access); MCP server (`getDatasetInfo`, `getSchema`, `queryDataset`, `findProperties`, `getProperty`), every response carries `source{runId, rootCid, manifestCid, syncedAt}`.
- **Agent:** Vercel AI SDK tool loop (geocode → radius search → open permits → read-only SQL) answering the README prompts with PIN-cited, source-linked rows and explicit assumptions.

## Known limitations

- Run history corrections (2026-11-11, data only, noted in each affected row): the initial bulk load ran as separate fetch and stage commands without a run row, so row `20261110T195816Z` was reconstructed from the staged batches (fetch times were not recorded); rows written on the development host before the database session was pinned to UTC were shifted by −2 h. Details: `docs/pipeline.md` (Run history).
- Roofing classifier trade-off: the stricter Chicago rule also drops genuine roof replacements done inside renovation permits (estimated ~6% of the 6,161 Chicago non-Easy/Express permits it removes, about 350), and 3,671 property roof ages changed in run `20261111T113057Z`, mostly properties losing a reroof anchor and falling back to a lower-confidence basis. Ten of the 30 remaining long-open permits are Cook Assessor permits with multi-scope descriptions; a Cook-side veto was measured but not applied because it also drops genuine roof jobs.
- Neither permit feed carries a completion date; closure is derived from terminal status, so open duration counts from the issue date.
- Gateways: the README's example gateways `ipfs.io` and `dweb.link` retired HTTP retrieval on 2026-09-21 (https://gatewaychanges.ipfs.io/), so they answer 429 and no longer serve content. The demo proves retrieval through `gw.ipfs-lens.dev` and `gateway.pinata.cloud`, two separately operated public gateways, with matching size and SHA-256. Pinata is also a pinning provider, so this shows two gateways, not two independent pin holders. Historical 429 results stay in the committed verification records.
- Pinata's free tier holds one full snapshot, so only the newest snapshot has two pins; older ones rely on Filebase plus their CAR releases.
- Incremental windows follow each source's `:updated_at`. Cook County republishes its Assessor datasets monthly and Chicago permits roughly daily, so most refreshes fetch 0 rows; source deletions are not reconciled (upsert only).
- BBB: 21 contractors have archived A+ profiles, labelled stale with capture date unknown; 129 are unavailable after the robots check was blocked. Others are unknown, never presented as current ratings.
- Source links: record-specific source URLs were malformed in the published bytes (they returned HTTP 400). They are now generated correctly and repaired at read time without changing published bytes, manifests or CIDs; the original value is kept as `source_url_original`. Details: `docs/source-links-r3.md`.
- Verification: unit tests, build, lint and CI pass. Hosted Playwright passed 99/99 (11 cases x 9 browser/viewport variants) against build `4dafad5`, including both README prompts and the canonical demo journey. Later changes (source links, automatic publication, classifier and roof-age rules) were verified by unit/integration tests, CI and live probes; the full hosted suite was not re-run on them. The demo video shows run `20261110T221716Z`, the snapshot served when it was recorded.
- Suburban permits come from the Assessor's monthly feed (what municipalities report), not from each municipal portal; Cook County Clerk recordings and Treasurer data have no bulk export.
