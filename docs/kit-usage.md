# Team-kit usage (Soofi XYZ team kit, rev 88df319)

This repository was built with the kit's agents and skills as the reference for "what good looks like".
`arceus` routing for this story: primary `oracle` (county mining and publication) with `use-oracle`,
`county-discovery`, `county-readiness-preflight`, `county-permit-adapter`, `county-ingest-run`,
`bbb-harvest`, `query-db-loading-matching`, `deploy-open-data-mcp`; supporting `metagross`
(`build-frontend-backends`) for the explorer UI/API and `alakazam` (`build-ai-agents`,
`build-rag-systems`) for the agent; baseline `apply-engineering-guidelines` for every task.
The kit plugin is enabled for this project in `.claude/settings.json`.

## Deviations, stated plainly

- **Hosting:** the live runtime runs in Docker on a VM behind Caddy (zero marginal cost for the
  assessment), not on Amplify + Lambda. The CDK stack in `infra/cdk` is the kit-shaped deployment
  and `cdk synth` runs in CI; `cdk deploy` was not run (no AWS account in this exercise).
- **Publication path:** the README requires per-run artifact manifests, CARs, new CIDs per republish
  and multi-gateway retrieval, which this repo implements. The kit's `oracle` publishes through Atlas
  (one Atlas county-page PR merged by a Prism code owner, global IPNS, Elephant MCP 2.0 sync). Atlas
  needs a code-owner merge and Cook County is not in the Elephant Lexicon, so the Atlas step is
  documented as the follow-up: the `manifest.json` objects map 1:1 onto Atlas data groups
  (`<table>/*.parquet` = Parquet partitions, the CAR = archive).
- **BBB:** harvested through the Internet Archive only, because bbb.org blocks this host at `robots.txt`
  (HTTP 403). The kit's next step is approved access through `https://developer.bbb.org/`; until then
  every BBB value is `stale` (archive timestamp recorded) or `unavailable` with a reason. See `docs/bbb.md`.
- **Store:** DuckDB + Parquet instead of the kit's Restate + PostgreSQL Query DB, as the README requires.
- **Models:** OpenAI through the AI SDK instead of Bedrock; in-process retrieval instead of OpenSearch.
- **Pinning:** Filebase (CAR import) and Pinata (folder upload) rather than the kit's Filebase Kubo RPC example.
